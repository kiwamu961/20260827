# AI物件写真分類サービス
## 企画概要書

2026/09/15  
作成者: 渡邉極

経営・事業判断用サマリー（[企画書](proposal.md)の要約版）

---

# 解決する課題

- 物件写真が撮影順のまま保管・掲載され、顧客が浴室、キッチン、玄関などの見たい場所を探しにくい。
- 撮影・入稿担当者は、写真の選別、分類、ファイル名変更に時間を要する。
- 物件探しに必要な情報へすぐ到達できる写真表示により、物件比較と内見判断を支援する。

---

# 提供するサービス

1物件分の写真をまとめてアップロードすると、AIが写真を自動分類する。

1. YOLOが画像内の設備・家具を検出する
2. JavaScriptの分類処理が検出物と信頼度を基にカテゴリを判定する
3. 担当者が分類結果を確認・修正する
4. 自社の物件検索・物件詳細サービスに分類済み写真を表示する

分類結果はカテゴリ別の画面で確認でき、自社サービスへの表示に利用する。

---

# 顧客が探せる7カテゴリ

| カテゴリ | 主な確認内容 |
| --- | --- |
| 浴室 | 浴室の広さ、設備、清潔感 |
| トイレ | 設備、清潔感 |
| リビング | 室内の広さ、家具配置、採光 |
| 玄関 | 出入りのしやすさ、下足入れ |
| キッチン | 調理のしやすさ、設備、収納 |
| 洗面所 | 洗面・洗濯のしやすさ、収納 |
| バルコニー | 日当たり、物干し場所、眺望 |

---

# 想定する導入先

- 賃貸・売買仲介会社
- 物件管理会社
- 不動産ポータル・物件検索サービスを提供する事業者

不動産事業者が、自社の物件登録・物件検索サービスへ組み込んで利用するBtoBサービスとして提供する。

利用者は写真を登録する担当者と、各社のサービスで物件を探す顧客である。

# 収益モデル

| 項目 | Normal | Pro |
| --- | ---: | ---: |
| 月額料金 | 10,000円（税別） | 50,000円（税別） |
| 月間写真処理数 | 3,000枚まで | 20,000枚まで |
| 1回のアップロード | 50枚まで | 100枚まで |
| 一括アップロード | 対象外 | 200枚まで |
| 元画像保存 | 処理完了後7日 | 処理完了後30日 |
| 分類済み画像・結果保存 | 30日 | 90日 |

---

# コストと利益率

| 項目 | Normal | Pro |
| --- | ---: | ---: |
| 月額売上 | 10,000円 | 50,000円 |
| 月間変動費 | 1,900〜3,450円 | 9,000〜17,300円 |
| 月間粗利 | 6,550〜8,100円 | 32,700〜41,000円 |
| 粗利率 | 約66〜81% | 約65〜82% |

変動費にはYOLO推論基盤、ストレージ・画像転送、監視・ログ、決済手数料を含む。元画像を期限後に自動削除することが採算維持の前提である。

---

# MVPの範囲と進め方

| 期間 | 実施内容 |
| --- | --- |
| 0.5日 | 対象カテゴリ、評価用写真、利用シナリオを確定 |
| 0.5日 | 写真アップロード、YOLO検出、JavaScript分類、カテゴリ別表示、手動修正 |
| 0.5日 | 分類結果の確認、評価用写真での分類確認、デモ準備 |

今回のゴールは、JPG・PNG写真のアップロード、7カテゴリと未分類への自動分類、確認・修正、分類結果の画面表示が動作する状態である。

MVP完成後は次段階として自社の物件写真で運用実験を行い、分類精度、処理時間、運用負荷を確認した上で、対象事業者への導入を進める。

---

# 成功指標とリスク

| 観点 | 確認内容 |
| --- | --- |
| 写真整理時間 | 手動整理と比べた1物件あたりの分類・確認時間 |
| 修正率 | AI分類後に担当者がカテゴリを変更した写真の割合 |
| 未分類率 | AIが判定できず未分類になった写真の割合 |
| 顧客の到達性 | 指定カテゴリの写真を短時間で見つけられるか |

誤分類への対策として、自動確定ではなく担当者の確認・修正を必須とし、低信頼度の写真は未分類として扱う。
