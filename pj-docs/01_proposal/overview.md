# AI物件写真分類サービス
## 企画概要書

2026/09/15  
作成者: 渡邉極

経営・事業判断用サマリー（[企画書](proposal.md)の要約版）

---

# 解決する課題

- 物件写真が撮影順のまま保管・掲載され、顧客が浴室、キッチン、玄関などの見たい場所を探しにくい。
- 撮影・入稿担当者は、写真の選別、分類、ファイル名変更に時間を要する。
- 物件探しに必要な情報へすぐ到達できる写真表示により、物件比較と内見判断を支援する。

---

# 提供するサービス

1物件分の写真をまとめてアップロードすると、AIが写真を自動分類する。

1. YOLOが画像内の設備・家具を検出する
2. Pythonの分類処理が検出物と信頼度を基にカテゴリを判定する
3. 担当者が分類結果を確認・修正する
4. 自社の物件検索・物件詳細サービスに分類済み写真を表示する

MVPでは、分類済み写真をカテゴリ別のZIPファイルとしても出力する。

---

# 顧客が探せる7カテゴリ

| カテゴリ | 主な確認内容 |
| --- | --- |
| 浴室 | 浴室の広さ、設備、清潔感 |
| トイレ | 設備、清潔感 |
| リビング | 室内の広さ、家具配置、採光 |
| 玄関 | 出入りのしやすさ、下足入れ |
| キッチン | 調理のしやすさ、設備、収納 |
| 洗面所 | 洗面・洗濯のしやすさ、収納 |
| バルコニー | 日当たり、物干し場所、眺望 |

---

# 想定する導入先

- 賃貸・売買仲介会社
- 物件管理会社
- 不動産ポータル・物件検索サービスを提供する事業者

不動産事業者が、自社の物件登録・物件検索サービスへ組み込んで利用するBtoBサービスとして提供する。

利用者は写真を登録する担当者と、各社のサービスで物件を探す顧客である。

---

# 収益モデル

| 項目 | 内容 |
| --- | --- |
| 提供形態 | 月額サブスクリプション |
| 想定料金 | 月額10,000円（税別） |
| 課金対象 | 不動産事業者 |
| 利用上限 | 月間の処理物件数または写真枚数で設定予定 |

MVPでは課金機能を実装せず、対象事業者へのデモと利用価値の検証を優先する。

---

# MVPの範囲と進め方

| 期間 | 実施内容 |
| --- | --- |
| 0.5日 | 対象カテゴリ、評価用写真、利用シナリオを確定 |
| 1日 | 写真アップロード、YOLO検出、Python分類、カテゴリ別表示 |
| 0.5日 | 手動修正、ZIP出力 |
| 0.5日 | 評価用写真での分類確認、デモ準備 |

対象はJPG・PNG写真のアップロード、7カテゴリと未分類への自動分類、確認・修正、ZIP出力である。

---

# 成功指標とリスク

| 観点 | 確認内容 |
| --- | --- |
| 写真整理時間 | 手動整理と比べた1物件あたりの分類・確認時間 |
| 修正率 | AI分類後に担当者がカテゴリを変更した写真の割合 |
| 未分類率 | AIが判定できず未分類になった写真の割合 |
| 顧客の到達性 | 指定カテゴリの写真を短時間で見つけられるか |

誤分類への対策として、自動確定ではなく担当者の確認・修正を必須とし、低信頼度の写真は未分類として扱う。
