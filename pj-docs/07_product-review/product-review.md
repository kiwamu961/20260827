# AI物件写真分類サービス
## 製品完成物レビュー

2026/09/16
対象: PhotoSort プロトタイプ

---

# 1. 製品概要

| 項目 | 内容 |
| --- | --- |
| 製品名 | PhotoSort（AI物件写真分類サービス） |
| 目的 | 物件写真を検出物からカテゴリ別に整理する |
| 対象範囲 | アップロード、YOLO推論、処理状況、分類結果、手動修正 |
| 推論環境 | FastAPI + Ultralytics YOLO、`yolo11n.pt`、CPU実行 |
| 公開方式 | GitHub Pages（画面）とローカルAPI（実推論） |
| 関連資料 | [要件定義書](../02_requirements/requirements.md)、[外部設計書](../04_external-design/external-design.md) |

GitHub Pagesは静的画面の公開用とし、実YOLO推論はローカルFastAPIへ分離している。

---

# 2. これまでの成果

- JPG・PNGの複数選択、ドラッグ&ドロップ、最大50枚制御
- `backend/app.py` にFastAPIの`/api/infer`と`/api/health`を実装
- `yolo11n.pt`の初回ダウンロード、読み込み、CPU実行を確認
- 画像形式、破損画像、10MB超過のAPI側検証
- YOLOのクラス名、信頼度、矩形領域をJSONで返却
- ブラウザーから画像をAPIへ送信し、推論結果をカテゴリ分類へ接続
- 1枚の推論失敗で全体を停止せず、失敗写真を未分類として継続
- カテゴリタブ、件数、検出根拠、手動分類変更を実装
- 手動変更時の`corrected`フラグ設定
- PC・モバイル向けレスポンシブ画面

# 5. 既知の制限事項

| No | 内容 | 対応方針 |
| --- | --- | --- |
| 1 | `yolo11n.pt`はCOCO汎用モデルで、浴室や玄関を直接分類しない | 物件写真用モデルまたは追加学習を検討 |
| 2 | 分類ルールは検出物の優先順で、信頼度閾値・同率判定が未実装 | 要件の判定ルールへ拡張 |
| 3 | 手動修正結果はメモリ上だけ | 保存方式を決定して永続化 |
| 4 | 処理結果の破棄画面が未実装 | SC-05と確認ダイアログを追加 |
| 5 | 自動テスト、実ブラウザー確認が未実施 | Playwrightと主要シナリオを追加 |
| 6 | GitHub Pages単独では実YOLO推論できない | FastAPIを同一環境またはHTTPSで提供 |

---

# 6. 製品受け入れ判定

## 現時点の判定

**条件付き不合格（プロトタイプ継続）**

実YOLO推論をローカルAPIへ接続し、検出結果を画面の分類処理へ渡せる状態になった。ただし、物件特化の分類精度、信頼度ルール、結果保存・破棄、自動テストが未完了のため、本番出荷可とは判定しない。

---

# 7. 今後の対応

1. 信頼度閾値・同率候補判定・信頼度表示を実装する
2. 手動修正結果の保存と処理結果の破棄を実装する
3. 物件写真に対する評価用データと精度指標を定義する
4. Chrome/Edgeの主要操作をPlaywrightで自動化する
5. 外部公開時のHTTPS、認証、アクセス制御、レート制限を設計する
